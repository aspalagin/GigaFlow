GigaFlow 0.3.1 — установка

Для Mac с Apple Silicon (M1 или новее), macOS 26.2 или новее.

1. Перетащите GigaFlow.app в папку Applications рядом.
2. Извлеките образ диска и откройте GigaFlow из «Программы».
3. Если macOS заблокирует запуск неизвестного разработчика:
   откройте «Системные настройки → Конфиденциальность и безопасность»,
   нажмите «Всё равно открыть» для GigaFlow и подтвердите запуск.
4. В GigaFlow разрешите микрофон и вставку текста.
   В «Универсальном доступе» включите GigaFlow.
5. Закройте окно настройки и дождитесь готовности модели в строке меню.
6. Выберите поле для текста. Нажмите Control + Shift + Пробел,
   скажите фразу и нажмите это сочетание ещё раз.

Python, модель GigaAM и зависимости уже внутри приложения.
Terminal, Xcode, Homebrew и доступ к сети для диктовки не нужны.
Запись распознаётся локально; Enter автоматически не нажимается.

Приложение подписано постоянным локальным сертификатом, но не прошло
нотарификацию Apple. Устанавливать сертификаты или отключать защиту macOS
не требуется. Подробнее о штатном подтверждении:
https://support.apple.com/102445

Автозапуск можно включить в «Основные → Объекты входа и расширения»,
добавив GigaFlow в список приложений для запуска при входе.
Кнопка Forward на мыши поддерживается через необязательный Hammerspoon.
Исходники и инструкции: https://github.com/aspalagin/GigaFlow
Этот выпуск: https://github.com/aspalagin/GigaFlow/releases/tag/v0.3.1
Файл установщика: GigaFlow-0.3.1-arm64.dmg

Для обновления завершите диктовку и выберите «Выйти из GigaFlow» в меню.
Замените приложение новой версией в той же папке, где находится текущая
копия: например, /Applications или ~/Applications. Не оставляйте две копии:
автозапуск и интеграция Hammerspoon могут продолжать указывать на прежний
путь и запускать старую версию.
