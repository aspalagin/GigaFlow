# GigaFlow

**Local voice dictation for macOS, powered by GigaAM v3 and MLX.**

Нажми **Ctrl + Shift + Пробел**, скажи фразу, нажми ещё раз — текст появится в активном поле. GigaFlow распознаёт речь локально на Mac, показывает небольшую капсулу записи и живёт в строке меню.

## Что умеет

- **Локальная диктовка:** GigaAM v3 e2e RNNT через MLX, без облачного API для распознавания.
- **Два нажатия:** первое начинает запись, второе завершает её и вставляет результат. Ctrl + Shift + Пробел и F18 работают без дополнительных программ; Forward на мыши подключается через Hammerspoon.
- **Капсула записи:** уровень микрофона, таймер, кнопки остановки и отмены; размер настраивается.
- **Вставка в исходное поле:** проверка приложения, окна и доступного поля ввода. Для Codex есть отдельная проверка, когда редактор не предоставляет Accessibility-элемент.
- **Текст без последней точки:** одиночная завершающая точка убирается, внутренняя пунктуация сохраняется. Дополнительного LLM-редактирования нет.
- **Постоянная локальная подпись:** обновления сохраняют идентичность приложения для разрешений macOS.
- **Автозапуск:** при входе в macOS, по желанию.
- **Автообновления:** новые версии скачиваются из GitHub и устанавливаются в подходящий момент без ручной работы с DMG.

## Скачать и установить

**[Скачать GigaFlow 0.4.0 для Apple Silicon](https://github.com/aspalagin/GigaFlow/releases/latest)** — выберите файл `GigaFlow-0.4.0-arm64.dmg` в разделе Assets.

Требуется **Mac с Apple Silicon и macOS 26.2 или новее**. Готовое приложение включает Python, библиотеки и модель GigaAM. Устанавливать среду, скачивать модель отдельно или собирать код не нужно. После скачивания DMG установка и распознавание работают без интернета.

1. Откройте DMG и перетащите **GigaFlow** в **Applications / Программы**.
2. Откройте GigaFlow из папки «Программы».
3. Эта версия **не нотарифицирована Apple** и использует собственный сертификат издателя. Если macOS заблокировала запуск, откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть (Open Anyway)** для GigaFlow и подтвердите запуск. Это штатное исключение для конкретного приложения; установка сертификатов и команды Terminal не нужны. [Инструкция Apple](https://support.apple.com/en-gb/102445).
4. В окне GigaFlow разрешите микрофон и вставку текста. В **Конфиденциальность и безопасность → Универсальный доступ** включите GigaFlow.
5. Закройте окно настройки, дождитесь готовности модели в меню и выберите поле для текста. Нажмите **Ctrl + Shift + Пробел**, скажите фразу и нажмите сочетание ещё раз.

Приложение отправляет Cmd+V, но не нажимает Enter. F18 тоже работает; если сочетание занято другим приложением, состояние доступных клавиш видно в GigaFlow. Кнопка остановки на капсуле завершает диктовку, крестик отменяет её.

Рабочая конфигурация проекта — Mac mini M4 с 16 ГБ памяти. Поддержка Intel Mac не предусмотрена. Нижняя граница macOS определяется встроенными библиотеками MLX, а не только версией, для которой компилируется интерфейс.

## Кнопка Forward через Hammerspoon

Для обычной диктовки Hammerspoon не нужен. Для кнопки мыши установите [Hammerspoon](https://www.hammerspoon.org/) и разрешите ему Универсальный доступ. В существующий `~/.hammerspoon/init.lua` добавьте:

```lua
gigaflow = dofile("/Applications/GigaFlow.app/Contents/Resources/Integrations/gigaflow.lua")
```

Если приложение установлено в другую папку, исправьте путь. Затем выберите **Reload Config** в меню Hammerspoon. Модуль использует Forward с номером `4`, как на MX Master 3S. Существующий `init.lua` заменять не нужно. Если эта кнопка уже привязана другим обработчиком, сначала устраните двойную привязку. Назначения остальных кнопок модуль не меняет.

## Автозапуск и обновление

Для автозапуска откройте **Системные настройки → Основные → Объекты входа и расширения** и добавьте GigaFlow в список открываемых при входе приложений. Для кнопки мыши добавьте также Hammerspoon.

Начиная с **0.4.0**, пункт **«Обновлять автоматически»** в меню включён по умолчанию. GigaFlow проверяет новые версии при запуске и затем каждые шесть часов, скачивает обновление в фоне и проверяет его подпись через Sparkle 2.10.1. Пункт **«Проверить обновления…»** запускает проверку вручную.

Автоматическая установка ждёт минимум 30 секунд без активности в приложении и на Mac. Она не прерывает запись, распознавание или вставку и не забирает фокус у поля ввода. Если последний текст ещё ждёт копирования через меню, перезапуск откладывается до его сохранения. Новая версия заменяет приложение в прежней папке, сохраняя путь для автозапуска и Hammerspoon.

**Переход с 0.3.1 и более ранних версий требует одной ручной установки:** завершите диктовку, выберите «Выйти из GigaFlow», скачайте DMG 0.4.0 и замените приложение **в той же папке**, например `/Applications` или `~/Applications`. После этого следующие выпуски получает само приложение. Не оставляйте две копии: автозапуск и Hammerspoon могут продолжать указывать на старую.

Чтобы отключить фоновые проверки и загрузки, снимите отметку **«Обновлять автоматически»**. Ручная проверка остаётся доступна. Для установки в папку, требующую прав администратора, macOS может запросить подтверждение.

Стабильная подпись сохраняет идентичность приложения между выпусками. При переходе с собственной сборки, подписанной другим сертификатом, разрешения может потребоваться выдать заново.

## Приватность и ограничения

Запись хранится во временном аудиофайле и удаляется после обработки или отмены. После аварийного завершения временный файл может остаться. Последний распознанный текст хранится в памяти приложения и доступен через меню для копирования.

Распознавание по-прежнему работает без сети. Для проверки и загрузки обновлений GigaFlow обращается к GitHub и его CDN; аудио, распознанный текст и анонимный системный профиль туда не отправляются. Отключение автообновлений не влияет на диктовку.

Перед вставкой проверяется исходное место ввода. Если оно изменилось, результат остаётся в меню. Прежний буфер обмена восстанавливается через секунду, если за это время его не изменило другое приложение.

В Codex иногда недоступен сам Accessibility-элемент редактора. В таком случае GigaFlow проверяет то же окно, приложение и отсутствие пользовательской навигации. Автоматическую смену поля внутри одного окна при отсутствующем Accessibility-элементе определить нельзя.

Одна запись ограничена 119 секундами. Длинная речь разделяется около пауз на фрагменты до 20 секунд; непрерывная речь может потерять слово на границе. Приложение ориентировано на русскую диктовку.

Диагностика приложения не сохраняет текст полей, заголовки окон или распознанные фразы:

- `~/Library/Application Support/GigaFlow/status.json` — текущее состояние и разрешения.
- `~/Library/Application Support/GigaFlow/focus-events.json` — последние 50 событий записи и вставки, включая причины отказов.
- `~/Library/Logs/GigaFlow/worker.log` — ошибки рабочего процесса распознавания.

Статус `paste_sent` означает отправку Cmd+V, а не подтверждение приёма текста приложением.

## Для разработчиков: сборка из исходников

Этот раздел нужен только для изменения кода или собственной сборки. Пользователям готового DMG он не требуется.

Нужны Apple Silicon, macOS **26.2+** для закреплённого runtime, Python **3.11 для arm64** и Xcode Command Line Tools (`xcode-select --install`). Полный Xcode не нужен. Интернет используется для первоначальной установки зависимостей и модели. Deployment target интерфейса сам по себе не означает поддержку macOS 14 всей средой распознавания.

Скрипт сборки также получает закреплённый Sparkle 2.10.1 и проверяет SHA256 его архива. Кеш зависимости находится в игнорируемой Git папке `vendor/`. В сборках без встроенного runtime обновления приложения отключены: такая среда обновляется из исходников по инструкции ниже.

### 1. Исходники и модель

```sh
mkdir -p "$HOME/Developer"
git clone https://github.com/aspalagin/GigaFlow.git "$HOME/Developer/GigaFlow"
cd "$HOME/Developer/GigaFlow"
bash scripts/setup-runtime.sh
```

Если Python 3.11 установлен по другому пути:

```sh
GIGAFLOW_PYTHON=/absolute/path/to/python3.11 bash scripts/setup-runtime.sh
```

Для сборки из исходников скрипт создаёт среду в `~/Developer/gigaam-pilot/.venv`, устанавливает версии из `requirements.lock.txt` и скачивает закреплённую версию модели в `~/Developer/gigaam-pilot/models/gigaam-v3-e2e-rnnt-mlx`. Сборка без встроенного runtime использует эту папку — не перемещайте её после установки.

Если рабочая среда GigaFlow уже существует, **пропустите этот шаг**. Скрипт не изменяет существующую `.venv`. Для загрузки или проверки модели отдельно:

```sh
"$HOME/Developer/gigaam-pilot/.venv/bin/python" scripts/download-model.py
```

Она проверяет собственный манифест и не перезаписывает неизвестную существующую модель.

### 2. Постоянная подпись и сборка

Для собственной сборки один раз создайте локальный сертификат и разрешите его использование для подписи. Команду доверия запускайте именно в локальном Terminal: macOS может показать системное подтверждение. Пользователям готового DMG эти команды не нужны.

```sh
"$HOME/Developer/gigaam-pilot/.venv/bin/python" app/setup-signing.py
bash app/enable-signing-trust.command
bash app/build.sh
bash scripts/install-app.sh
```

Сертификат и закрытый ключ принадлежат вашему Mac. Они хранятся вне репозитория в `~/Library/Application Support/GigaFlow/Signing`. Сохраняйте эту папку: потеря или замена сертификата потребует заново выдать разрешения приложению. Повторный `setup-signing.py` проверяет существующую подпись и не генерирует замену автоматически.

Для обновления собственной сборки выйдите из GigaFlow и выполните:

```sh
git pull --ff-only
bash app/build.sh
bash scripts/install-app.sh
```

Установщик сохраняет резервную копию предыдущей версии и запускает обновлённое приложение. Изменение `requirements.lock.txt` может потребовать отдельного обновления среды — существующая среда автоматически не перезаписывается.

### Проверки и выпуск DMG

```sh
GIGAFLOW_TEST_PYTHON="$HOME/Developer/gigaam-pilot/.venv/bin/python" bash scripts/check.sh
```

Python-тесты проверяют обработку аудио и протокол рабочего процесса; проверки Swift — политику фокуса и горячих клавиш, счётчики ввода, сохранение буфера обмена, завершение записи, канал связи с процессом распознавания, блокировку повторного запуска и условия безопасного перезапуска для обновления. Скрипт также компилирует интерфейс. Эти проверки работают без записи микрофона и вставки в чужие приложения.

Диагностический режим приложения `--self-test` проверяет восстановление отдельного тестового буфера обмена и распознавание эталонного аудио через MLX. Он не регистрирует глобальные горячие клавиши и не принимает команды Hammerspoon. Логику горячих клавиш покрывают проверки политики; фактическую регистрацию сочетаний и полный путь «кнопка → голос → поле» проверяют вручную.

Упаковка переносимой среды, подпись и публикация готового DMG описаны в [docs/RELEASING.md](docs/RELEASING.md), устройство ленты обновлений — в [docs/UPDATES.md](docs/UPDATES.md).

### Размер капсулы

По умолчанию капсула записи занимает **240 × 48 точек**. Уже заданная настройка масштаба сохраняется. Для изменения без пересборки:

```sh
defaults write local.arseniy.gigaflow HUDScale -float 0.6666666667
```

Перезапустите GigaFlow, чтобы применить значение. Диапазон — от `0.15` до `1.0`; `1.0` соответствует 360 × 72 точкам во время записи.
