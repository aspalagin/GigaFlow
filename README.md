# GigaFlow

**Local voice dictation for macOS, powered by GigaAM v3 and MLX.**

Нажми кнопку мыши, скажи фразу, нажми ещё раз — текст появится в активном поле. GigaFlow распознаёт речь локально на Mac, показывает небольшую капсулу записи и живёт в строке меню.

## Что умеет

- **Локальная диктовка:** GigaAM v3 e2e RNNT через MLX, без облачного API для распознавания.
- **Два нажатия:** первое начинает запись, второе завершает её и вставляет результат. Forward на мыши подключается через Hammerspoon; F18 работает как клавиатурная альтернатива.
- **Капсула записи:** уровень микрофона, таймер, кнопки остановки и отмены; размер настраивается.
- **Вставка в исходное поле:** проверка приложения, окна и доступного поля ввода. Для Codex есть отдельная проверка, когда редактор не предоставляет Accessibility-элемент.
- **Текст без последней точки:** одиночная завершающая точка убирается, внутренняя пунктуация сохраняется. Дополнительного LLM-редактирования нет.
- **Постоянная локальная подпись:** обновления сохраняют идентичность приложения для разрешений macOS.
- **Автозапуск:** при входе в macOS, по желанию.

Это исходники приложения для самостоятельной сборки. Готовый подписанный и нотарифицированный установщик пока не выпускается; модель скачивается отдельно при настройке среды.

## Требования

- Mac с Apple Silicon и macOS 14 или новее.
- Python **3.11 для arm64** и Xcode Command Line Tools (`xcode-select --install`). Полный Xcode не нужен.
- Интернет для первоначальной установки зависимостей и модели. После настройки распознавание работает офлайн.
- [Hammerspoon](https://www.hammerspoon.org/) — только для кнопки мыши.

Приложение проверено на Mac mini M4 с 16 ГБ памяти. Минимальная версия macOS задана сборкой; все сочетания устройств и версий macOS не тестировались.

## Установка

Команды ниже выполняются в Terminal на Mac.

### 1. Исходники и модель

```sh
mkdir -p "$HOME/Developer"
git clone https://github.com/aspalagin/GigaFlow.git "$HOME/Developer/GigaFlow"
cd "$HOME/Developer/GigaFlow"
bash scripts/setup-runtime.sh
```

Если Python 3.11 установлен по другому пути:

```sh
GIGAFLOW_PYTHON=/absolute/path/to/python3.11 bash scripts/setup-runtime.sh
```

Скрипт создаёт среду в `~/Developer/gigaam-pilot/.venv`, устанавливает версии из `requirements.lock.txt` и скачивает закреплённую версию модели в `~/Developer/gigaam-pilot/models/gigaam-v3-e2e-rnnt-mlx`. Приложение использует эту папку — не перемещайте её после установки.

Если рабочая среда GigaFlow уже существует, **пропустите этот шаг**. Скрипт не изменяет существующую `.venv`. Для повторной загрузки модели, ранее установленной этим скриптом, есть отдельная команда:

```sh
"$HOME/Developer/gigaam-pilot/.venv/bin/python" scripts/download-model.py
```

Она проверяет собственный манифест и не перезаписывает неизвестную существующую модель.

### 2. Постоянная подпись и сборка

Один раз создайте локальный сертификат и разрешите его использование для подписи. Команду доверия запускайте именно в локальном Terminal: macOS может показать системное подтверждение.

```sh
"$HOME/Developer/gigaam-pilot/.venv/bin/python" app/setup-signing.py
bash app/enable-signing-trust.command
bash app/build.sh
bash scripts/install-app.sh
```

Сертификат и закрытый ключ принадлежат вашему Mac. Они хранятся вне репозитория в `~/Library/Application Support/GigaFlow/Signing`. Сохраняйте эту папку: потеря или замена сертификата потребует заново выдать разрешения приложению. Повторный `setup-signing.py` проверяет существующую подпись и не генерирует замену автоматически.

### 3. Разрешения и первая диктовка

В окне GigaFlow разрешите микрофон и вставку текста. В системных настройках **Конфиденциальность и безопасность → Универсальный доступ** включите GigaFlow.

Закройте окно настройки, дождитесь готовности модели в меню и выберите поле для текста. Нажмите F18, скажите фразу и нажмите F18 ещё раз. Приложение отправляет Cmd+V; Enter не нажимается. Если клавиатура не имеет F18, используйте пункт меню GigaFlow или настройте кнопку мыши.

## Кнопка Forward через Hammerspoon

Установите Hammerspoon и разрешите ему Универсальный доступ. В существующий `~/.hammerspoon/init.lua` добавьте:

```lua
gigaflow = dofile(os.getenv("HOME") .. "/Developer/GigaFlow/integrations/hammerspoon/gigaflow.lua")
```

Затем выберите **Reload Config** в меню Hammerspoon. Модуль использует Forward с номером `4`, как на MX Master 3S. Существующий `init.lua` заменять не нужно. Если эта кнопка уже привязана другим обработчиком, сначала устраните двойную привязку. Назначения остальных кнопок модуль не меняет.

## Автозапуск и размер капсулы

Чтобы GigaFlow запускался при входе в macOS:

```sh
osascript app/enable-autostart.applescript
```

Для кнопки мыши включите также автозапуск Hammerspoon. Управлять обоими приложениями можно в **Системные настройки → Основные → Объекты входа и расширения**.

Установщик задаёт новой установке капсулу **240 × 48 точек**. Изменить масштаб можно без пересборки:

```sh
defaults write local.arseniy.gigaflow HUDScale -float 0.6666666667
```

Перезапустите GigaFlow, чтобы применить значение. Диапазон — от `0.15` до `1.0`; `1.0` соответствует 360 × 72 точкам во время записи. Установщик сохраняет уже заданный масштаб.

## Обновление

Завершите текущую диктовку и выберите «Выйти из GigaFlow» в меню приложения. Затем выполните:

```sh
git pull --ff-only
bash app/build.sh
bash scripts/install-app.sh
```

Установщик сохраняет резервную копию предыдущей версии и запускает обновлённое приложение. Сохраняйте установленный путь, bundle ID и локальный сертификат. Скрипт сборки использует прежнюю подпись; повторно настраивать сертификат и разрешения при обычном обновлении не требуется. Изменение `requirements.lock.txt` может потребовать отдельного обновления среды — существующая среда автоматически не перезаписывается.

## Приватность и ограничения

Запись хранится во временном аудиофайле и удаляется после обработки или отмены. После аварийного завершения временный файл может остаться. Последний распознанный текст хранится в памяти приложения и доступен через меню для копирования.

Перед вставкой проверяется исходное место ввода. Если оно изменилось, результат остаётся в меню. Прежний буфер обмена восстанавливается через секунду, если за это время его не изменило другое приложение.

В Codex иногда недоступен сам Accessibility-элемент редактора. В таком случае GigaFlow проверяет то же окно, приложение и отсутствие пользовательской навигации. Автоматическую смену поля внутри одного окна при отсутствующем Accessibility-элементе определить нельзя.

Одна запись ограничена 119 секундами. Длинная речь разделяется около пауз на фрагменты до 20 секунд; непрерывная речь может потерять слово на границе. Приложение ориентировано на русскую диктовку.

Диагностика приложения не сохраняет текст полей, заголовки окон или распознанные фразы:

- `~/Library/Application Support/GigaFlow/status.json` — текущее состояние и разрешения.
- `~/Library/Application Support/GigaFlow/focus-events.json` — последние 50 событий записи и вставки, включая причины отказов.
- `~/Library/Logs/GigaFlow/worker.log` — ошибки рабочего процесса распознавания.

Статус `paste_sent` означает отправку Cmd+V, а не подтверждение приёма текста приложением.

## Проверки

Из корня репозитория на Mac:

```sh
"$HOME/Developer/gigaam-pilot/.venv/bin/python" -m unittest discover -s app/tests -v
mkdir -p app/build
xcrun swiftc -swift-version 5 \
  -framework AppKit -framework ApplicationServices \
  app/FocusTracking.swift app/InputCounterGuard.swift app/tests/FocusPolicyChecks.swift \
  -o app/build/focus-policy-checks
app/build/focus-policy-checks
```

Шесть Python-тестов проверяют обработку аудио и протокол рабочего процесса. 32 проверки Swift проверяют политику фокуса и счётчики ввода. Эти проверки работают без записи микрофона и вставки в чужие приложения; полный путь «кнопка → голос → поле» проверяется вручную.
